# Creator Skills

面向自媒体创作者的可复用 AI 技能集合，用于内容学习、视频拆解与创作复盘。

## 技能

| 技能 | 用途 |
|---|---|
| [video-breakdown](video-breakdown/) | 从视频链接或本地素材整理账号信息、时间码文案、成片脚本与八角度图表报告 |

## 使用

查看 [视频拆解技能说明](video-breakdown/README.md) 与 [SKILL.md](video-breakdown/SKILL.md)。当前执行器针对 Windows、PowerShell 与 D 盘路径配置，换设备使用时需相应调整路径与依赖。

源码不包含模型、运行环境、缓存、视频素材或历史拆解报告。
