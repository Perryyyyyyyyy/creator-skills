# 报告整理与导出规范

用于图文版、文案整合和阅读结构调整。默认提供 Markdown 主稿与图片内嵌的单文件 HTML，便于学习、复盘与分享；不自动发布或发送报告。

## 报告结构

| 部分 | 内容 | 表现形式 |
|---|---|---|
| 核心结论 | 最值得学习的机制与适用条件 | 三至五条短要点，按内容决定数量 |
| 基础信息 | 账号、粉丝显示、发布时间、视频信息、单条互动 | 账号与单条数据分表 |
| 文案梗概与段落脚本 | 时间、摘要、画面、段落作用 | 一张对照时间轴，避免重复大表 |
| 八角度分析 | 观察、可能作用、可借鉴方法 | 每节配一张图表与短分点 |
| 学习应用 | 可以尝试的创作改动 | 行动清单 |
| 数据与使用说明 | 日期、区间、缺失、抽样与校对状态 | 集中简短说明 |
| 完整逐字稿 | 可以交付的全文和时间码 | 按实际内容分章，主稿和独立附件同时提供 |

不要把本例的九个段落、具体标题、账号数据和情绪走势作为所有视频的默认内容。账号定位为推断时保留依据，未取得的封面不能用第一帧代替。

“学习应用”保留原有建议，再补充段落骨架、口播风格规则、声画对应与“原视频做法—依据—方法—本人素材需求／已提供素材”表。第六角度既有情绪折线，也有文字层面的口播风格分析，不用新增风格内容替换原有情绪图。

## 文案整理

- 主报告开头有明显的文案入口，不让用户在多个文件间寻找。
- 阅读版可合并相邻片段并加标点，不改观点。完整性应与所有转写片段核对，防止漏段或重复。
- 保留原始转写。错词修正需要音频、字幕或用户提供的可靠依据，内部保留校对记录。
- 机器稿存在明显错词时标为待校对，不将全长转写称为听校完成。整理阅读版时也不能隐藏这一状态。
- 全文使用依据依当前任务和适用内容规则处理；已明确的相关授权不重复索要，不泛化到其他素材。

## 清理与保留

阅读稿不包含内部 t/f 编号、source segments、HTML 注释、JSON、工具绝对路径、日志、安装步骤、命令代码块和重复处理状态。

内部保留媒体指纹、证据、原始文字、数据快照、恢复信息和生成脚本。清理针对阅读稿，不删除实现代码或核验资料。

数据日期、区间值、近似时间、来源和校对状态是必要信息，集中保留；不要为了简洁把推断包装成已核实结论。

## 文件与版式

- 清晰标题、短段落、分点为主；表格用于可比较的数据与时间轴，不把长解释塞入窄格。
- 统一图表字体和配色，图中文字应能正常阅读。生成后逐张查看。
- 图文版目录只放阅读产物和必要图表；不打包模型、运行时、原始大视频或内部 JSON。
- HTML 中内嵌图表，转发不依赖原电脑路径；Markdown 主稿和独立逐字稿一并保留。
- 先备份再编辑，同步主稿、阅读副本和图文版。再次导出可能覆盖人工排版，保留最新源稿。

## 打包工具

使用本技能的 `scripts/package_report.py` 将已写好的 Markdown 清理并导出 HTML。D 盘现有 Python 可直接执行，无需新装 Markdown 库。

```powershell
& 'D:/codexfile/mySkill/video-breakdown/.runtime/python/python.exe' -B `
  'D:/codex_home/skills/video-breakdown/scripts/package_report.py' `
  --source 'D:/任务/output/视频拆解报告.md' `
  --output 'D:/任务/output/图文版/视频拆解报告_图文版.html' `
  --asset-root 'D:/任务'
```

支持本流程的标题、分点、编号列表、简单表格、粗体、链接、本地 PNG/JPEG。工具移除内部注释和标为 internal 的内部代码块，生成干净 Markdown 副本并内嵌本地图片；不下载远程图片，也不自动生成分析或判断授权。有实际教学意义的代码默认保留，显式加 --strip-code-blocks 才删除所有代码块。

图片只能来自源稿目录或显式指定的素材目录。复杂嵌套列表、合并表格、Word/PDF 等应使用实际可用的对应工具，不冒充任意格式转换器。需要 DOCX/PDF 时完成相应版面检查，不能仅改扩展名。

## 原创阶段交付

收到本人想做的视频内容后，另行交付原创文案、含画面草稿的拍摄脚本、待补素材与核对记录，不覆盖原拆解报告和完整逐字稿。完整口播独立可复制；脚本里的口播与采用稿一致。

脚本默认交付Markdown与自包含HTML。每个拟拍镜头都有实际生成的草图，包含人物区、素材区、字幕区和必要动作标注；提供分页总览与逐镜头图。草稿标明“非成片”，已存在素材与待录屏占位明确区分。

`render_storyboard.py` 输出图像、索引及脚本Markdown；使用 `package_report.py` 将该稿打包成图片内嵌HTML。逐张查看草图、核对数量和镜头编号、核对HTML内嵌版本。美术草图不替代录制后的声画验证，未录音的时长保留“拟定”。
