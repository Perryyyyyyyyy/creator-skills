# 八角度图表规范

图表解释关系、阶段或数值，不用装饰性图标代替分析。内容随实际视频变化，不复用历史案例的姓名、标题、数值、节点数或情绪波形。

## 每个角度的默认配图

| 角度 | 推荐图表 | 依据与边界 |
|---|---|---|
| 目标人群 | 受众需求匹配矩阵：需求阶段—核心困惑—内容回应—预期帮助 | 逐行对应；阶段可重叠，推断不冒充后台人口画像 |
| 选题与价值 | 价值递进阶梯图；无递进关系时用问题解决流程图 | 突出每步形成的成果；高度不代表量化效果 |
| 标题与封面 | 标题原句分色拆解；取得封面时另加实际封面标注 | 原句片段与解释同色关联；缺失封面明确说明 |
| 开头钩子 | 按时长绘制的开头节拍时间轴＋内容与作用索引 | 区分内容事实与作用假设；不是留存曲线 |
| 内容结构 | 全片连续内容轨道＋段落索引 | 色块宽度对应时长；短段落用编号标识 |
| 情绪与表达 | 覆盖全片的定性情绪折线 | 段落、可见表情及已听辨表达的依据 |
| 视听与节奏 | 真实关键帧＋表达任务对照板 | 标注时间、信息区与人物区；不凭抽样推算占比 |
| 互动与转化 | 同尺度公开互动柱状图 | 本条真实计数、定义及观察时间 |

缺少足够素材时保留该节的缺失说明，不捏造一张完整图来凑齐八张。

## 受众需求匹配矩阵

每行将一项需求与视频的具体回应、预期帮助对应起来，方便横向阅读。人群存在交叉时，优先按需求阶段组织，不将同一位观众可能同时具有的需求画成互斥人群。阶段名称随实际内容设置，不套用固定的入门、实践、求职路径。预期帮助是分析判断，不能写成已验证的效果。

## 价值递进阶梯图

内容确有递进关系时，用从左下到右上的阶梯呈现。每级优先突出本阶段形成的成果，关键动作放在下方；图下用一句话说明这些成果与选题价值的关系。级数和措辞根据本条内容确定，不套用固定求职路径。阶梯高度只表示逻辑递进，不编造能力增幅、转化率或成功概率，也不将内容建议写成实际效果。

## 标题原句分色拆解

保留实际标题的用词、顺序及标点，用不同颜色区分信息任务；下方同色解释片段的作用，不强行将所有标题拆成相同四类。标注阅读作用为分析判断，不推定点击率。独立发布封面未取得时保留缺失说明，不用视频第一帧冒充封面。

## 开头节拍时间轴

区段按实际起止时间成比例绘制，短区段用编号连接下方索引。索引分别列出时间、交代的内容和可能提供的观看理由。由转写近似还原的边界明确标注；作用属于机制假设，不等于实测留存或点击效果。

## 全片内容轨道

横轴覆盖媒体开始至结束，段落连续按时间顺序排列；色块宽度按真实段落时长计算。用少量颜色表示有依据的内容归组，以编号连接段落名称、起止时间、时长和叙事任务。避免将长标题挤进短色块。检查轨道覆盖、空隙和重叠，分组不篡改边界；需要比较时长时可附条形图。

## 关键帧与表达任务对照板

从已观察的本条视频中选择代表性画面，不用生成示意画面冒充证据。优先保留完整构图和比例，注明实际时间码；如局部放大则明确标为局部。按需用色框、字母或引线标出信息区、人物区，并说明这些是新增分析标注。图片下解释承载信息、表达任务与可借鉴方法，不能从单帧推算画面占比或完整剪辑节奏。未独立听校的配乐、音效继续注明缺失。

## 情绪折线图

- 横轴为视频开始至结束的实际时间，节点按本条内容段落设定；用段落中点时说明含义。
- 纵轴用较低、中等、较高等有序文字表示相对唤起或张力。没有测量数据时不编造 0 至 100 分等数值。
- 节点注明段落或关键事件，并给出判断理由。折线连接定性节点，不代表间隔内连续测量。
- 高低不代表情绪正负、内容优劣或满意度；情绪类型需要时另标好奇、担忧、认同等。
- 不强制高开低走或先降后升。未听校声音时不能声称检测到语调或音乐变化。
- 图内或紧邻图表注明“基于内容结构的定性分析，非观众情绪实测”；不把情绪线称作观众留存曲线。

## 数据口径

- 未取得的互动项不设为零。收藏除以点赞称为收藏与点赞比；没有播放量不算播放互动率。
- 互动计数和不是独立人数。账号总量与本条指标分开，“1万+”不绘成精确的 10000。
- 段落时长来自结束时间减开始时间；检查全片覆盖、空白和重叠，不为凑总长篡改边界。
- 没有连续观察时不估算画面时长占比、平均镜头时长、语速或音效频率。

## 制作与检查

优先使用 D 盘已有 Python/Pillow 或当前可用的标准绘图工具。绘图脚本放内部目录，PNG 放图文版目录的 charts 子目录。已有系统中文字体可读取，新增依赖和字体仍放 D 盘。

每张图有标题、可读标签、必要单位和依据说明。同一系列稳定配色；定量柱状图一般从零起。长标签换行或以节点编号对应说明，不缩成难读小字。

逐张查看导出图片，检查重叠、截断、缺字和坐标。修改图片后重新打包 HTML，确认其内嵌的是最新图，而不只是磁盘上的 PNG 更新。
