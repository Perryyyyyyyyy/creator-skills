# Video Breakdown · 视频拆解与图文报告

将视频链接或本地素材整理成可核对的中文拆解报告，适合学习视频表达、复盘内容结构和记录创作方法。

## 输出内容

- 账号信息、发布时间与公开互动数据，记录来源、采集时间和显示精度。
- 带时间码的文案、字幕与成片还原脚本；适用时提供完整逐字稿。
- 八角度分析：目标人群、选题价值、标题封面、开头钩子、内容结构、情绪表达、视听节奏、互动转化。
- 需求匹配矩阵、价值阶梯、标题分色拆解、时间轨道、定性情绪折线、真实关键帧对照等图表。
- 结构化 Markdown 和图片内嵌的单文件 HTML 图文报告。

## 工作方式

执行器通过 yt-dlp 获取可访问的视频，使用 FFmpeg 校验和提取音频，使用 faster-whisper 在 CPU 上转写并生成抽样关键帧。助手阅读素材、撰写分析和图表后，再整理图文报告。

命令行预处理结束不代表内容分析完成。机器文案标注校对状态；情绪图是基于内容的定性判断，不是观众情绪或留存实测。没有内置自动 OCR、全量评论采集或 DOCX 导出。

## 安装与运行

这是当前针对 Windows、PowerShell 和 D 盘目录配置的个人 Skill。完整规范见 [SKILL.md](SKILL.md)，执行说明见 [references/usage.md](references/usage.md)。

1. 将本目录作为 `video-breakdown` 技能目录放入 Codex 的 skills 目录。
2. 本机执行器当前使用 `D:/codexfile/mySkill/video-breakdown`，FFmpeg 与 FFprobe 使用 `D:/Apps/FFmpeg/bin`。在其他设备使用时，需要相应调整路径与依赖配置。
3. `scripts/setup.ps1` 用于在 D 盘准备便携 Python 与固定版本依赖；转写模型首次使用时需要下载。运行前使用 `run.ps1 doctor` 检查环境。
4. 在 Codex 中调用 `$video-breakdown`，提供视频链接或本地文件，并说明所需格式。

后续已准备好模型的任务可使用离线模式。链接受访问限制时，可提供本地视频继续处理。

## 目录

| 路径 | 用途 |
|---|---|
| `SKILL.md` | 技能入口与核心约束 |
| `agents/openai.yaml` | 技能显示信息与默认提示词 |
| `references/` | 执行、证据、图表和报告导出规范 |
| `scripts/` | 素材处理、环境准备和报告打包工具 |
| `tests/` | 执行器与报告打包的验证用例 |
| `run.ps1` | 本机命令入口 |
| `requirements.lock.txt` | 固定依赖版本 |

运行时、模型、缓存、原视频和历史任务保存在本地，不包含在源码包中。生成报告时分别记录事实、作者观点与分析推断；全文转写的使用范围依具体素材和任务确定。
